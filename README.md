# checkmk_swos
CheckMK special Agent to monitor Mikrotik SWoS throught web requests

Features
- System information and uptime
- Temperatures
- Fans
- Power supplies
- Ports (link, speed, duplex, flow control, RSTP, LAG, PoE)
- Traffic, packet and error rates on the port services
- SFP / QSFP modules
- PoE total power
- Spanning tree (RSTP)
- Link aggregation (LAG)
